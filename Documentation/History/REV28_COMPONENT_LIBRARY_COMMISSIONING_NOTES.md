# Rev28 — Industrial Component Library, Terminal Maps & Commissioning Evidence

Rev28 promotes cabinet construction from generic device classes into reusable component definitions, explicit field-device terminal maps, commissioning sheets, latent workmanship defects, and generated loop-document bundles.

Research-informed scope includes terminal families with feed-through/fuse/disconnect/test functions; separate power, signal, network, pneumatic, flame-sense and ground identities; and commissioning evidence that remains distinct from construction completion.

Vendor-aware terminal maps are educational abstractions. They are not substitutes for current manufacturer instructions, approved drawings, hazardous-location engineering, code requirements, or site procedures.

The latent-defect engine allows workmanship to remain apparently functional at commissioning and later emerge under thermal, load, vibration, and moisture stress. This is intended to connect panel construction history to later diagnostic gameplay.
