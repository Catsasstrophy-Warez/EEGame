# Rev26 Panel Assembly & Commissioning Execution

Rev26 makes construction actions mutate panel truth rather than merely checking a completed cabinet.

Key additions:
- crimp truth: conductor/ferrule sizing, compression quality, added resistance
- terminal torque truth
- stripped-core preparation and strand-damage state
- landing and wire-marker state
- ordered assembly event ledger
- continuity and insulation evidence gates
- controlled energization gate
- I/O checkout and loop-calibration commissioning gate

The model deliberately avoids presenting simplified thresholds as NEC/NFPA/UL or manufacturer requirements. Device-specific torque, stripping, test voltage, hazardous-area, intrinsic-safety, SCCR, and burner-safety requirements must come from applicable authoritative documentation in later content authoring.
