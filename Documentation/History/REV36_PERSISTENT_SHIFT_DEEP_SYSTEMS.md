# Rev36 — Persistent Shift & Deep Diagnostic Systems

Rev36 moves the project from isolated diagnostic demonstrations toward a continuously evolving industrial world.

## Implemented
- Persistent Codable plant shift with concurrent work orders.
- Unresolved jobs age while the player works elsewhere.
- Degrading assets continue changing with load, heat, oxidation and vibration.
- Solver snapshot contract for voltage/current/temperature/quality visualization.
- Current-flow particle model driven by branch current.
- Physical two-probe placement session.
- Triggered multi-channel oscilloscope foundation.
- Thermal-field interpolation from identity-bound pixels.
- Historian/SOE replay state reconstruction.
- Motor Academy execution/grading with safety penalties.
- CAN/network packet decoding foundation.
- Hierarchical component cutaway state.
- Career progression that distinguishes verified root-cause work.
- JSON save/reload round trip for shift state.

## Competitive analysis carried forward
EveryCircuit validates immediate animated electrical feedback and live parameter interaction. Factory I/O validates authored industrial scenes, I/O connectivity, instructor constraints and intentionally simple failure injection. FluidSIM validates multi-domain component libraries, real/virtual measuring tools, component fault models and learner profiles. Automation Studio validates dynamic state visualization, component configuration, conditional failures, realistic instruments, plotting, multiple simulation speeds and cross-domain coupling.

Electric Engineer adapts these patterns around a stricter rule: advanced cases should derive symptoms, measurements, historian events and visualizations from shared machine state whenever practical. Instructor overrides remain useful for basic teaching, but they are not the simulation ceiling.
