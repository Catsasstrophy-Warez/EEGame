# Rev33 — Competitive Feature Assimilation

Rev33 converts the competitive research into native Electric Engineer systems without copying proprietary UI, art, text, scenarios, or source code. The governing rule remains **one physical truth**.

## Adapted product patterns
- Electrician job games → career/work-order loop and proof-of-repair closure.
- VR electrician games → object-level manipulation vocabulary.
- ElectroSim/wiring trainers → Observe → Guided → Assisted → Independent → Faulted → Master.
- Relay trainers → synchronized physical/schematic/functional/signal/logic/process views.
- EveryCircuit/Falstad → optional Electrical Vision + immediate causality.
- ElectricVLab/CRUMB → instrument physics + 3D workbench concept.
- Multisim/SPICE education → analysis-mode roadmap separate from real-time gameplay.
- FluidSIM/Automation Studio → multidisciplinary physical coupling.
- Factory I/O → reusable scenes/instructor fault authoring, but with deeper physical fault primitives.
- PLCLogix → realistic PLC progression plus Trace to Field.
- CircuitVerse → hierarchy, reusable blocks, timing/testbench thinking.
- Turing Complete → progressive construction of complexity.
- SHENZHEN I/O → documentation as gameplay/evidence.
- Proteus CAN → CAN/DBC/diagnostics/fault-finding curriculum.

## New executable/domain systems
`Rev33ExperienceRuntime`, `EECompetitiveFeatureMatrix`, `EEElectricalVision`, `EEInstrumentLocker`, `EEMotorAcademy`, `EETechnicalLibrary`, `EEEvidenceEngine`, `EEIntermittentConnection`, `EEProofOfRepair`, `EEHierarchyExplorer`, and expert demonstration playback.

## Safety / authenticity
These systems are educational simulation abstractions. Real electrical, combustion, hazardous-location, lockout/tagout and OEM service work requires applicable procedures, qualified personnel, and authoritative documentation. Modeled torque/range/fault thresholds must not be presented as universal field criteria.
