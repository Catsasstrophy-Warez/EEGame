# Rev50 Physicalized Forensics

Rev50 is an integration and tidying revision. It preserves the hard natural-gas / coal-mining boundary while making existing systems more physical and mutually navigable.

## Added
- Facility path geometry with travel mode, time, distance and elevation change.
- Physical 3D coordinates and access state for instrument test points.
- Probe/sensor/clamp placement roles and instrument readiness checks.
- Evidence likelihood engine for explicit hypothesis updates.
- Synchronized forensic overlays spanning channels, alarms/events, PLC context, network, thermal, vibration and player evidence.
- Bench consequence layer for short-circuit/protection outcomes.
- Rev50 production shell exposing the integrated workflows.

## Safety / authenticity
All numerical models and thresholds remain educational simulation unless independently verified against current authoritative requirements. The game does not replace approved mine plans, site procedures, LOTO, NFPA/NEC requirements, MSHA requirements, OEM documentation, or qualified field judgment.

## Validation
Portable Swift validation is performed with Swift 6.2.1/Linux. Xcode, signing, iPhone, iPad and Mac Catalyst remain a separate validation gate.
