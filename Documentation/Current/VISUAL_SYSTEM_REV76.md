# Rev76 Industrial Visual System

Rev76 replaces the generic GroupBox/list presentation with an industrial diagnostic workstation language.

Production visual principles:
- machine-specific physical equipment instead of generic cards;
- MCC bucket, PLC rack, terminal strip, wire duct and conductor identity;
- persistent `TB1:12` cross-highlighting;
- dark instrument-panel surfaces with restrained cyan/amber/green diagnostic state;
- monospaced technical readouts;
- live waveform and simulation state;
- schematic/panel/PLC/process identity continuity;
- Electrical Vision driven by simulation truth;
- large touch targets and horizontal instrument/action rails on iPhone;
- graphics are functional: tap, measure, trace, explain, plot, replay.

The visual target is a field technician's instrument cart, MCC room and engineering workstation compressed into a coherent mobile interface, not a generic productivity dashboard.
