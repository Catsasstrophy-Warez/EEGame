# Rev71 Competitive UX Assimilation

Rev71 adapts reusable interaction patterns identified across Automation Studio, Factory I/O, PLCLogix, LogixPro/LadderLab, PLC Fiddle, CODESYS, VirtualPlant-style labs, CircuitVerse, Proteus VSM, Tinkercad Circuits, Turing Complete, SHENZHEN I/O, PhET CCK, and IndustrialSim-style trainers. It does not reproduce proprietary artwork, UI layouts, code, or course content.

## Three UX levels
- Quick Bench: minimal-chrome instant experimentation.
- Engineering Workbench: libraries, hierarchy, properties, plots, timing, testbenches, PLC project, tags, BOM, technical docs.
- Field Technician: physical equipment, tools, drawings, work order, evidence and forensic cursor.

## Production foundations added
Workspace modes; Run/Pause/Slow/physics-step/PLC-step/network-step/replay; seven synchronized representations; component library records; property inspector state; plot and timing channels; generalized testbench; reusable assemblies; BOM; PLC project tree; tag watch/force-quality state; contextual technical documents; cutaway layers; facility authoring state; professional multidimensional score.

## Rule
Every surface must resolve to shared equipment identities and simulation/evidence provenance. UI may visualize or author intent, but must not invent electrical/process truth.
