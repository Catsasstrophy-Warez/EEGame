# Rev61 — I&E + Controls Deep Professional Academy

Rev61 turns the I&E Technician and Controls Technician paths into deep, simulation-backed professional curricula rather than topic lists.

## I&E Technician
29 track families span electrical interfaces, measurement physics, pressure/DP, flow, level, temperature, analytical measurement, discrete instrumentation, loop power, cable/shielding, hazardous interfaces, calibration/metrology, HART-style diagnostics, valve positioners, final control, instrument air, PLC I/O, scaling, process dynamics, PID, MCC/VFD interfaces, historian/SOE, condition monitoring, intermittent faults, commissioning, separate natural-gas and coal applications, forensic RCA, and documentation.

Each track has four major themes and eight competency levels: recognize, explain, guided performance, independent performance, diagnosis, optimization, leadership, and forensic defense. Nodes require evidence, instruments, documents, fault families, prerequisites, transfer contexts, and safety-critical classification.

## Controls Technician
32 track families span relay foundations, PLC architecture and scan behavior, discrete/analog I/O, scaling, timers/counters, sequencing/state machines, permissives/interlocks, PID, motion/drives/VFDs, remote I/O, Ethernet/serial/Modbus/EtherNet-IP concepts, HMI, alarms, historian/SOE, managed switching, network forensics, redundancy, safety controls, configuration management, cybersecurity awareness, embedded I/O, CAN, commissioning, controls forensics, and documentation.

The diagnostic model explicitly trains separation of physical faults, field wiring faults, I/O faults, logic faults, configuration faults, network faults, HMI presentation faults, and historical-data/time-sync faults.

## Practical system
120 deep practical station definitions provide 15,360 deterministic baseline variants. Every practical requires an as-found state, simulation-backed measurement, competing hypothesis, discriminating test, root cause, and as-left proof. Fault identity reveals, replacement-answer shortcuts, and scripted next-measurement prompts are prohibited.

## Training doctrine
One physical truth. Difficulty changes assistance, never physics. Higher levels require defensible evidence and transfer to unfamiliar equipment. Natural-gas and coal process truth remain separate.

Rev61 is the current portable-source baseline. ScenarioEngine target build verified on Swift 6.2.1/Linux. Full test bundle did not finish linking within the available execution window.
