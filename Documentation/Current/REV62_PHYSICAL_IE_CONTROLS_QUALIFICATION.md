# Rev62 — Physical I&E / Controls Qualification

Rev62 converts the deep Rev61 I&E and Controls curriculum into a physical qualification layer. Labs are evidence-driven configurations of simulation truth rather than scripted answer puzzles.

## I&E laboratories
Pressure-transmitter chain; DP manifold/impulse system; 4–20 mA compliance/burden; calibration/as-found/as-left; valve/positioner response; integrated process forensics.

## Controls laboratories
PLC rack/channel wiring; scan microscope; state machine/sequence recovery; VFD ownership; industrial Ethernet; serial; CAN physical layer; synchronized PLC/SOE/historian replay; integrated first-divergence board.

Every lab defines physical identities, test points, permitted actions, documents, hidden fault families, safety gates, evidence requirements, deterministic variants, repair and recommissioning proof.

The core diagnostic question is: **Where does physical truth first diverge from represented truth?**
