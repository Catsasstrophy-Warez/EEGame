# Rev63 Integrated I&E / Controls Simulation

Rev63 converts the Rev62 qualification definitions into executable educational physics: impulse-line response, transmitter dynamics, 4–20 mA compliance/burden, MNA loop cross-checking, calibration error, valve/positioner mechanics, PLC scan/scaling, deterministic network faults, CAN termination, synchronized replay, and evidence-gated qualification completion.

## Truth chain
Process → impulse system → transmitter → current loop → raw I/O → scaling → PLC logic → network → HMI/historian → evidence → repair → recommissioning.

Numerical constants are generic educational model parameters unless separately sourced. They are not OEM, site, regulatory, or acceptance criteria.
