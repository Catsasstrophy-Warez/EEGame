# Rev66 Deep Physical Controls

Rev66 attacks the next combined performance and qualification ceiling without changing the project's one-physical-truth rule.

## Numerical execution
- Precomputed CSR `(row,column) -> value-index` stamp plans for topology-stable restamping.
- Electrical-island discovery for future deterministic structured-concurrency scheduling. Ground is a shared reference, not an artificial coupling between unrelated islands.
- Solver performance reports include unknowns, nonzeros, island count, iterations, residual and convergence.
- GPU/Metal sparse solving remains a benchmark-driven future option, not a default.

## I&E physical depth
- DMM input impedance and current-range burden are explicit instrument properties.
- Five-valve DP manifold model adds high/low blocks, equalization, vents and independent restrictions.
- Transmitter model separates sensor error, trim, configured range, damping and output.

## Controls depth
- Trigger-aware scope crossing detection.
- Scan-by-scan ladder snapshots.
- Deterministic register transaction capture layered over network delivery truth.
- CAN quality combines termination, common-mode offset and timing/propagation effects.

## Forensics
- Bounded replay ring prevents unbounded forensic memory growth and supports nearest-time lookup.
- The next UI pass should bind one cursor to physical, schematic, PLC, network, HMI, historian and Golden Thread surfaces.

All physical values are educational simulation parameters unless separately sourced and verified. Regulatory/site acceptance criteria are not encoded here.
