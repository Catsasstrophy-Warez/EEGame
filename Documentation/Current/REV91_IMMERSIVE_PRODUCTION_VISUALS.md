# Rev91 Immersive Production Visuals
Adds a RealityKit MCC volume when available, terminal-to-terminal harness visualization, interactive red/black lead placement, bounded transient-recorder display, animated motor/process machinery, and facility environment/light/sound-state presentation. All diagnostic values continue to originate in EEFacilityMeasurementFrame88.

The RealityKit cabinet is intentionally procedural geometry at this stage, not a claim of photogrammetric/OEM cabinet fidelity. The transient UI maintains a bounded display buffer; the next physics pass should bind it directly to the ScenarioEngine transient ring buffer for true captured waveforms.
